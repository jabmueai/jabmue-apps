# 🚌 รถมาหรือยัง · ดูรถเมล์/สองแถวต่างจังหวัดแบบสด

ทำตามคำขอจากผู้ชมคลิป: ผู้โดยสารรอรถริมถนนไม่รู้ว่ารถจะมาเมื่อไหร่ แอปนี้ให้คนขับแชร์ GPS จากมือถือ แล้วผู้โดยสารเปิดดูว่ารถอยู่ตรงไหน อีกประมาณกี่นาทีจะถึงป้าย (แผนที่ OpenStreetMap)

| ใคร | ลิงก์ | ทำอะไร |
|---|---|---|
| ผู้โดยสาร | `/` | เลือกสาย → เลือกป้าย (หรือกด "หาป้ายใกล้ฉัน") → เห็นว่ารถอีกกี่นาทีจะถึง · มีปุ่ม 🔊 อ่านออกเสียง · ส่งลิงก์ทาง LINE · ครั้งต่อไปเปิดแล้วเห็นเลย |
| คนขับ | `/driver` | กดชื่อตัวเอง → ใส่รหัส → เลือกทาง → กด "เริ่มวิ่ง" · ปุ่ม "รถเต็ม" · ระบบสลับขาไป/ขากลับให้เองเมื่อกลับรถ |
| ผู้ดูแล | `/admin` | เพิ่มสายรถ (แตะแผนที่ปักป้าย เส้นทางวิ่งตามถนนจริงให้อัตโนมัติ) · เวลารถออก · เพิ่มคนขับและรหัส · ดูรถทุกคันบนแผนที่ · ส่งลิงก์ |

ไม่ต้องสมัครสมาชิก ไม่ต้องติดตั้งจาก Store (เพิ่มลงหน้าจอโฮมได้)

📖 **วิธีใช้แบบละเอียด มีรูปทุกขั้นตอน:** หน้า `/help` ในแอป (เช่น https://jabmue-bus.vercel.app/help)

## Deploy บน Vercel (ฟรี)

1. เข้า [vercel.com/new](https://vercel.com/new) → Import repo นี้
2. **Root Directory** เลือก `bus` → กด Deploy
3. เข้าโปรเจกต์ → **Storage** → Create Database → **Upstash for Redis** (แพ็กเกจฟรี) → Connect กับโปรเจกต์นี้
4. **Deployments** → Redeploy (ให้ระบบเห็นฐานข้อมูล)
5. เปิด `https://<ชื่อโปรเจกต์>.vercel.app/admin` → ตั้งรหัสผู้ดูแลครั้งแรก → เริ่มใช้งาน

ไม่บังคับ: ตั้ง Environment Variable `ADMIN_PIN` ถ้าอยากกำหนดรหัสผู้ดูแลเอง (กันคนอื่นมาตั้งก่อน)

## ข้อควรรู้

- เวลาถึงเป็น **ค่าประมาณ** จากระยะทางตามเส้นทาง ÷ ความเร็วเฉลี่ยที่ผู้ดูแลตั้ง (ตั้งได้ 20/30/45/60 กม./ชม.)
- คนขับต้อง **เปิดหน้าคนขับค้างไว้** (ระบบกันจอดับให้) ถ้าปิดจอ/สลับแอป มือถือจะหยุดส่ง GPS → ผู้โดยสารเห็นว่า "สัญญาณหาย"
- ส่งตำแหน่งทุก ~10 วินาทีเมื่อรถวิ่ง · Upstash ฟรีพอสำหรับรถไม่กี่คัน ถ้ารถเยอะ/ผู้ใช้เยอะ อาจเกินโควตาฟรี
- ข้อมูลแผนที่ © ผู้ร่วมพัฒนา OpenStreetMap · ถ้าภาพแผนที่ OSM โหลดไม่ได้ (บางเน็ต/VPN) จะสลับไปใช้ CARTO เอง · ค้นหาสถานที่ (Nominatim, สำรองด้วย Photon) และเส้นทางตามถนน (OSRM) เรียกผ่าน `/api/bus` ของเราเอง · Leaflet เก็บไว้ใน `vendor/`

## ทดสอบในเครื่อง

```
cd bus && node dev-server.js   # http://localhost:3000 (เก็บข้อมูลในหน่วยความจำ · ถ้าอยู่หลัง proxy ใส่ NODE_USE_ENV_PROXY=1)
```

## ทดสอบอัตโนมัติ (QA 54 ข้อ)

```
node tests/qa.cjs https://<โปรเจกต์>.vercel.app ./shots <รหัสแอดมิน>
```
ครอบคลุม API/ความปลอดภัย, แอดมิน, คนขับ, ผู้โดยสาร · ทดสอบเว็บจริงได้ (สร้างสาย/คนขับชื่อ "QA ทดสอบ" แล้วลบและคืนข้อมูลเดิมให้ตอนจบ)
